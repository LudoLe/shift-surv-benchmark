\caption{Methods compared. ``Uses'' states what each method observes during
training; no practical method uses target labels, which enter only for
evaluation and for the analytic reference models. ``Acts on'' describes the
object the method modifies. ``Primary target'' denotes the property it is
designed to improve; representation- and reweighting-based methods may also
affect calibration as a side effect. Prior adjustment and Platt scaling are
implemented as monotone increasing probability transformations and therefore
leave AUROC unchanged. Hyperparameters were selected once, on a seed block
disjoint from every seed used for evaluation, by a criterion that never
observes target labels: importance-weighted cross-validation on the source
validation split for methods that see unlabeled target covariates, and
leave-one-source-out validation for those that do not. One value is frozen per
method rather than one per regime, since a deployable protocol cannot retune
for a shift it has not identified. Across the entire grid the selection
criterion moves by at most $0.004$ AUROC for any method (least for CORAL,
$0.0001$; most for IRM, $0.0038$), so the comparison does not rest on the
values chosen. On the real cohorts the same frozen values are used, except that
DANN and CDAN re-run their IWCV search per transfer --- an asymmetry that
favours the adversarial methods, which nonetheless do not exceed ERM.}
